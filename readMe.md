This mod adds a Multi Page Barrel,
inspired by cubex2's Multi Page Chest.
Please note that this mod is a completely 
independent project and does not use 
any source code or assets from the original mod.
If you encounter any issues, 
**please report them to me instead of contacting cubex2.**

Warning : If you set config to the maximum, the risk of chunk data corruption increases due to NBT size limits.
